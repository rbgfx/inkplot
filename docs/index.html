Quick start

From values to SVG

require "inkplot"

chart = Inkplot.line([3, 1, 4, 1, 5, 9], title: "A small series")
chart.save("series.svg")
Plain Ruby data

Arrays, hashes, CSV tables, and records with string or symbol keys.

SVG by default

Standalone SVG from Ruby's standard library. Optional PNG rendering is pure Ruby.

Useful scales

Linear, logarithmic, time, and ordered category axes, plus dark and light themes.
